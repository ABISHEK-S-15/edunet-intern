# 🧠 Chronic Disease Monitoring AI Agent

An AI-powered virtual health assistant for chronic disease care, built using IBM Watsonx.ai Studio's Agent Builder. This intelligent agent supports patients and healthcare providers by delivering personalized insights, real-time data monitoring, and AI-driven recommendations for chronic illnesses like diabetes, hypertension, and cardiovascular diseases.

---

## 📌 Features

- ✅ **Chronic Disease Detection**: Supports conditions like diabetes, hypertension, and heart disease.
- 🩺 **Wearable & EHR Integration**: Analyzes data from wearable devices and electronic health records.
- 🔄 **Real-Time Monitoring**: Continuously tracks health vitals and provides alerts or recommendations.
- 🧠 **AI-Driven Insights**: Uses IBM Granite foundation models to infer risks and suggest lifestyle or medication adjustments.
- 🔊 **Conversational Interface**: Built using Watsonx.ai Agent Builder to deliver natural, multi-turn conversations.
- 📝 **AI Report Generation**: Summarizes patient status, generates reports, and drafts care suggestions for healthcare providers.
- 📅 **Reminder System**: Notifies patients about medication, appointments, and health tracking.

## ⚙️ Setup Instructions

### Prerequisites
- IBM Cloud account (Lite Plan or above)
- Access to Watsonx.ai Studio
- Watsonx Agent Builder enabled

### Steps

1. **Create a Project** in [Watsonx.ai Studio](https://dataplatform.cloud.ibm.com)
2. **Enable Agent Builder** and create a new agent
3. **Upload Intents, Entities, and Skills**
4. Configure **model parameters** (temperature, top_p, etc.)
5. Use **Granite Model (e.g., granite-3-3-8b-instruct)** for generative capability
6. Deploy the agent and test through the Watsonx Web Chat UI
7. (Optional) Integrate with external APIs (wearable data, health records)
